# Interactive Profile Card

This project is a responsive and interactive personal profile card built with vanilla HTML, CSS, and JavaScript. It's designed to showcase user information in a clean, modern, and dynamic way.

## Features

- **Responsive Design:** The layout adapts seamlessly to desktop, tablet, and mobile devices.
- **Dynamic Time Display:** Shows the current time in milliseconds, updating in real-time.
- **Interactive Avatar Update:** Users can change the profile picture by clicking on the avatar to open a file dialog and select a new image.
- **Structured Information:** Clearly organized sections for a user bio, social media links, hobbies, and dislikes.
- **Data Test IDs:** Includes `data-testid` attributes on key elements for easy integration with automated testing frameworks.

## Tech Stack

- **HTML5:** For the semantic structure of the profile card.
- **CSS3:** For all styling, including Flexbox/Grid layouts and responsive media queries.
- **JavaScript (ES6+):** For all client-side interactivity, such as the live clock and image upload functionality.

## Getting Started

No build process or dependencies are required. To run this project:

1.  Clone this repository or download the files.
2.  Open the `ProfileCard.html` file directly in your web browser.
